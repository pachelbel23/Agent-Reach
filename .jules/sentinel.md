## 2026-03-30 - IPv6 Embedded IPv4 SSRF Bypass in Python ipaddress
**Vulnerability:** Python's `ipaddress.IPv6Address.is_global` returns `True` for IPv4-compatible (`::a.b.c.d`), IPv4-translated (`::ffff:0:a.b.c.d`), and NAT64 (`64:ff9b::a.b.c.d`) IPv6 addresses even if the embedded IPv4 address belongs to a private, loopback, or cloud-metadata network (e.g. `127.0.0.1`, `169.254.169.254`). Relying solely on `addr.is_global` allowed SSRF filter bypasses.
**Learning:** Python standard library `ipaddress` only sets `is_global = False` for IPv4-mapped (`::ffff:a.b.c.d`), but ignores IPv4-compatible (`::/96`), SIIT translated (`::ffff:0:0:0/96`), and NAT64 (`64:ff9b::/96`) representations. Additionally, mypy rejects accessing private attributes like `_ip` on `IPv6Address`; casting to `int(addr)` provides safe 128-bit integer unpacking without type checking errors.
**Prevention:** In URL validators, extract and unpack embedded 32-bit IPv4 integers from IPv6 prefixes before delegating to `IPv4Address(raw & 0xFFFFFFFF).is_global`.
