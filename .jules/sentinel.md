## 2026-10-25 - SSRF filter bypass via embedded IPv4 in IPv6 literals
**Vulnerability:** Python's `ipaddress` module considers IPv4-compatible (`::a.b.c.d`), IPv4-translated (`::ffff:0:a.b.c.d`), and NAT64 (`64:ff9b::a.b.c.d`) IPv6 addresses as `IPv6Address.is_global == True`, even when the embedded IPv4 address is non-global (such as loopback `127.0.0.1`, cloud metadata `169.254.169.254`, or private RFC1918 addresses). Calling only `literal_address.is_global` allowed internal hosts to bypass public URL validation in `normalize_public_http_url`.
**Learning:** `IPv6Address.is_global` only evaluates the IPv6 prefix/allocation rather than checking whether an embedded IPv4 address within transition or translation prefixes points to a private or loopback target.
**Prevention:** In URL and SSRF validation helpers, extract embedded IPv4 addresses from IPv6 addresses (checking `addr.ipv4_mapped` as well as unpacking 32-bit suffixes for `::/96`, `::ffff:0:0/96`, and `64:ff9b::/96` via `int(addr)`) and verify that `embedded.is_global` is also true.
